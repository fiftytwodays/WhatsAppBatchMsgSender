# WhatsAppBatchMsgSender
Send message and attachments to multiple contacts through WhatsApp web

## Install Chrome Driver
https://googlechromelabs.github.io/chrome-for-testing/

## Running the application

Create a properties file and provide it as environment variable when you run the application.
properties="D:\personal\mft\WhatsAppBatchMsgSender\src\main\resources\app.properties"
